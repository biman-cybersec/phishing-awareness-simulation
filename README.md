# 🔐 Phishing Awareness Simulation Project

## 📌 Overview

This project was developed as part of a Cyber Security Internship to demonstrate how phishing attacks exploit **human psychology** using social engineering techniques.

It simulates a real-world phishing scenario in a **controlled and ethical environment** to analyze user behavior and improve cybersecurity awareness.

---

## 🎯 Objectives

* Understand common phishing techniques
* Simulate phishing email and fake login page
* Analyze user interaction and behavior
* Measure awareness levels
* Suggest preventive security measures

## ⚙️ Methodology

1. Studied real-world phishing techniques
2. Designed a phishing email
3. Created a fake login page
4. Conducted a controlled simulation
5. Analyzed user responses

---

## 📊 Key Observations

* Many users clicked links due to urgency
* Some trusted email formatting blindly
* Only a few identified phishing attempts
* Human error is a major cybersecurity risk

---

## 🛡️ Preventive Measures

* Cybersecurity awareness training
* Verification of email sources
* Multi-Factor Authentication (MFA)
* Strong password policies

---

## 💡 Key Learnings

* Phishing attacks rely heavily on social engineering
* Awareness is the first line of defense
* Authentication alone is not sufficient
* Proper authorization is essential
